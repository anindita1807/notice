# noticeboard-api

A tiny Express API that returns a list of school notices.
It is the backend half of a two-repo demo for RepoVitals Projects
(frontend: `noticeboard-web`).

## Run

```bash
npm install
npm start
```

Open http://localhost:4000/api/notices to see the JSON.

> Note: dependency versions are pinned to older releases on purpose,
> so RepoVitals has something to flag. Do not use this in production.
